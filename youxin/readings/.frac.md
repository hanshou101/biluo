# .frac.md — public/youxin/readings

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

游心（闭眼听弈）的逐句读音资料，旁白念哪个音靠它。生成物，已提交、不手改，由 `scripts/youxin/build_readings.py`（`npm run youxin:readings`）生成，运行时按语料包按需 fetch。

## 2. 直属文件

- `default.json`：预设读音——音节表 `syllables`，加上 U+4E00–U+9FFF 每个字一个两位 64 进制的音节编号（`base` / `block`），区外字单列在 `others`。
- `<包 id，冒号换成 ~>.json`：每个语料包一份，只记与预设读音不同的例外，`{ "zh-Hans": { "篇.句": "位置:音节,…" }, "zh-Hant": {…} }`，位置按码位。主诗库的包直接用包名（如 `tang300.json`），经卷的包是 `scripture~<书 id>.json`。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 例外按 `包/篇/句/码位` 下标对齐语料包：`public/data/**` 或 `public/scripture/**` 重新生成（切句或顺序变了）后必须重跑 `npm run youxin:readings`，否则例外错位。

## 5. 什么时候需要下钻

- 改格式或查读法：读 `../../../src/youxin/readings.ts`（`ReadingTable`、`loadReadings`）和 `../../../scripts/youxin/.frac.md` 里 `build_readings.py` 一条。
