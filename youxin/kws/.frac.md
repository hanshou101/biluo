# .frac.md — public/youxin/kws

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

游心（闭眼听弈）的口令识别资料，运行时由 `@sherpaw/kws` 载入。生成物，已提交、不手改，由 `scripts/youxin/build_kws.py`（`npm run youxin:kws`）生成。

## 2. 直属文件

- `keywords.json`：口令表——每条口令的 `label`、所属组 `groups`、boost（`score`）、`threshold`，以及每种念法的记号序列 `matches`。
- `model.data`：int8 关键词识别模型的预载包，encoder / decoder / joiner 与 `tokens.txt` 按序串接成一个二进制。
- `model.json`：`model.data` 的目录——各文件的 `filename` / `start` / `end`、总长 `remote_package_size`，另记模型名与许可。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 三个文件是一套：`model.json` 的偏移要和 `model.data` 对得上，不单换其中一个。
- 改口令、门槛或念法，去 `scripts/youxin/` 改完重跑 `npm run youxin:kws`，不手改本目录。

## 5. 什么时候需要下钻

- 改口令标签、记号或门槛：读 `../../../scripts/youxin/.frac.md` 与 `build_kws.py`；标签要同步 `src/youxin/` 的 `intents.ts`，载入逻辑在 `listen.ts`。
