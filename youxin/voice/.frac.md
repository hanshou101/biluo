# .frac.md — public/youxin/voice

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

游心（闭眼听弈）的旁白声音包：把音节和整句提示拼成几张精灵图，运行时按需下载。生成物，已提交、不手改，由 `scripts/youxin/build_voice.py`（`npm run youxin:voice`）生成。

## 2. 直属文件

- `s<n>.m4a` / `s<n>.ogg`：音节精灵图，按音节在语料里出现的频率排；每张同时有 AAC（m4a）与 Opus（ogg）两种编码。
- `p<n>.m4a` / `p<n>.ogg`：整句提示精灵图（句子来自 `scripts/youxin/phrases.json` 与构建脚本另加的几类），同样 AAC 与 Opus 各一份。
- `index.json`：精灵图目录——`sprites`（每张的 `file` / `ogg` / `kind` / 首个可闻样本的时刻 `onset`）、`syl` 与 `phr`（每段的 [张, 起点, 长度]）、`missing`（念不出的音节）。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 精灵图和 `index.json` 是一套：换旁白声音或新增提示句，整套重跑 `npm run youxin:voice`，不单换其中几个文件。
- 提示句的键名被 `src/youxin/` 引用，改键名要同步。
- AAC 由 macOS 的 `afconvert` 出，换平台生成要改 `scripts/youxin/common.py`。

## 5. 什么时候需要下钻

- 改旁白怎么排、怎么对齐、AAC 解不了怎么退：读 `../../../src/youxin/voicebank.ts`；改合成与核对流程读 `../../../scripts/youxin/.frac.md` 里 `build_voice.py` 一条。
