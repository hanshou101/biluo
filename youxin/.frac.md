## 1. 本目录是什么

游心（闭眼听弈）运行时按需 fetch 的数据，全部由 `scripts/youxin/` 生成、已提交、不手改；Service Worker 不预缓存，用到才缓存（`vite.config.ts` 的 `youxin` 规则）。

## 2. 直属文件

- `hints.json`：闭眼提示 `{ 字: { w: { 读音: [词, "词的读音"] }, r: [部首序号, 部首外笔画] } }`（7,345 字，356 KB）。
- `voice/index.json` 与 `voice/s*.m4a|ogg`、`voice/p*.m4a|ogg`：旁白精灵图（音节按频率 12 张、提示句 2 张；每张 AAC 与 Opus 各一份）；`index.json` 记每段的 [张, 起点, 长度]、每张首个可闻样本的时刻 `onset`、念不出的音节 `missing`。
- `readings/default.json`：预设读音（音节表 + U+4E00–U+9FFF 每字两位 64 进制编号 + 区外字）；`readings/<包 id，冒号换成 ~>.json`：`{ "zh-Hans": { "篇.句": "位置:音节,…" }, "zh-Hant": {…} }`，位置按码位。
- `kws/keywords.json`：口令（标签、所属组、boost、门槛、每种念法的记号）；`kws/model.data` + `kws/model.json`：int8 关键词识别模型的预载包（`@sherpaw/kws` 的格式：文件串接 + `{files:[{filename,start,end}], remote_package_size}`）。

## 3. 子目录导航

无子目录（`voice/`、`readings/`、`kws/` 都是生成物，见上）。

## 4. 本层约束 / 约定 / 禁忌

- 读音例外按 `包/篇/句/码位` 下标对齐语料包：`public/data/**` 或 `public/scripture/**` 重新生成后必须重跑 `npm run youxin:readings`。
- 换旁白声音整套重跑 `npm run youxin:voice`（精灵图与 index.json 一起换）。
