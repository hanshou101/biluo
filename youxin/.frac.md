# .frac.md — public/youxin

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

游心（闭眼听弈）运行时按需 fetch 的数据，全部由 `scripts/youxin/` 生成、已提交、不手改；Service Worker 不预缓存，用到才缓存（`vite.config.ts` 的 `youxin` 规则）。

## 2. 直属文件

- `hints.json`：闭眼提示 `{ 字: { w: { 读音: [词, "词的读音"] }, r: [部首序号, 部首外笔画] } }`——每个字按它在语料里出现过的读音各给一个组词，另给部首与部首外笔画；由 `build_hints.py`（`npm run youxin:hints`）生成。

## 3. 子目录导航

- `kws/`：见 `kws/.frac.md`；口令表与 int8 关键词识别模型（`@sherpaw/kws` 预载包），`build_kws.py` 生成。
- `readings/`：见 `readings/.frac.md`；预设读音，加每个语料包逐句的读音例外，`build_readings.py` 生成。
- `voice/`：见 `voice/.frac.md`；旁白精灵图（AAC 与 Opus 各一份）和 `index.json`，`build_voice.py` 生成。

## 4. 本层约束 / 约定 / 禁忌

- 全是生成物：语料包（`public/data/**`、`public/scripture/**`）或旁白声音变了，按各子目录的 `.frac.md` 重跑对应 `npm run youxin:*`，不手改。

## 5. 什么时候需要下钻

- 改格式先看 `../../src/youxin/` 里读它们的模块：`readings.ts`、`voicebank.ts`、`listen.ts`、`player.ts`；生成侧读 `../../scripts/youxin/.frac.md`。
