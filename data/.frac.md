# .frac.md — public/data

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。

## 1. 本目录是什么

`scripts/build-data.ts`（`npm run data`）的输出，已提交，运行时由 `src/data/corpus.ts` fetch。

## 2. 直属文件

- `packs.json`：语料包索引——每包的 id / 名称 / 简介 / 来源 / 许可 / 首数 / 句数 / 精选首数 / 按句长（4·5·7·其他）统计，加上游版本 `generatedFrom`（poetry / xinhua / unihan）；含俳句包。
- `strokes.zh-Hans.json`：《新华字典》简体笔画 + Unihan 回落（只补字典没有的字，供日文汉字与查字），块编码（`base` 0x4E00、`code` 表、`block` 字符串）。
- `strokes.zh-Hant.json`：Unihan `kTotalStrokes` 的 zh-Hant 值，同样的块编码。

## 3. 子目录导航

- `packs/`：见 `packs/.frac.md`；每包每种文字一份 JSON，含俳句包。
