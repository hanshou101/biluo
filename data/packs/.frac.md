# .frac.md — public/data/packs

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

语料包：每包每种文字（`zh-Hans` / `zh-Hant`）一个 JSON，`{ id, name, script, source, license, poems: [{ title, author, type, lines[], featured? }] }`。同一包两种文字的 poems / lines 下标一一对应。由 `scripts/build-data.ts`（`npm run data`）生成，已提交，运行时按需 fetch。

## 2. 直属文件

文件名是 `<包 id>.<文字>.json`；包 id 与名称：

- `tang300.*`：唐诗三百首。
- `extras.*`：名篇补遗（三百首之外的名篇）。
- `qianjiashi.*`：千家诗。
- `song300.*`：宋词三百首。
- `nalan.*`：纳兰词。
- `shijing.*`：诗经。
- `haiku.*`：俳句（日语原文，一首一句；来源 `scripts/haiku.json`，公有领域）。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 不手改；各包的首数、句数、句长统计、来源以上一层的 `packs.json` 为准，重跑 `npm run data` 后随之更新。

## 5. 什么时候需要下钻

- 读取逻辑读 `src/data/.frac.md`；加包或改切句规则读 `scripts/build-data.ts`。
