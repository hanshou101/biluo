# .frac.md — public/art

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

内置的公有领域 / CC 古画（Wikimedia Commons 下载后缩小的 jpg）与索引。手工挑选，不是生成物。

## 2. 直属文件

- `index.json`：`ArtItem[]` 数组——每幅的 `id` / `file` / `title` / `artist` / `dynasty` / `museum` / `tags`（与 `src/art/art.ts` 的 `artTags` 词表对齐）/ `source`（Commons 文件页）/ `license` / `commonsArtist` / 宽高。
- `*.jpg`：每幅一张，文件名即 `id`（如 `hanjiang-dudiao.jpg`）。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 只放许可宽松、来源可回溯的作品；`license` 与 `source` 必填。要求署名的（CC BY-SA）把摄影者写进 `commonsArtist`。界面每幅图下方都会显示署名与许可，README 的古画说明也要列出。
- 单图缩到最长边 ≤ 1000 px、体积 300 KB 左右以内；本目录被 workbox `globIgnores` 排除在预缓存外，靠运行时缓存。
- 加一幅 = 放图 + 在 `index.json` 加一条（`tags` 用 `artTags` 会产出的词）。

## 5. 什么时候需要下钻

- 匹配逻辑与在线来源读 `src/art/.frac.md`。
