# .frac.md — public/scripture/books

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

一部书一个语料包，与诗词包同构：`{ id: 'scripture:<书>', name, script, source, license, unit: 'clause', plain: true, poems: [{ title, author, type, lines[], refs[] }] }`。`poems` 是章，`lines` 是段（一段 = 一局，带标点的原文），`refs` 是每段的出处标签（如 `1:1–3`、`1.3–4`）。由 `scripts/scripture/build.ts` 生成，已提交，运行时按需 fetch。

## 2. 直属文件

- `<书>.zh-Hans.json` / `<书>.zh-Hant.json`：每部书两种文字各一个。书 id：圣经各卷用通行的三字母代码（`gen` … `rev`）；`quran`；佛典 `xinjing` `jingang` `tanjing` `sishier` `yijiao`；儒典 `lunyu` `daxue` `zhongyong` `mengzi`；道典 `daodejing` `zhuangzi` `qingjing` `ganying`。

## 3. 子目录导航

无子目录。

## 4. 本层约束 / 约定 / 禁忌

- 不手改。同一部书两种文字的章、段一一对应，每段逐句的字数相同（管线里核对过，对不上不出包）。

## 5. 什么时候需要下钻

- 改分段口径、加书、换版本：去 `scripts/scripture/.frac.md`。
