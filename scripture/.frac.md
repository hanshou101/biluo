# .frac.md — public/scripture

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

经卷扩展的数据，全部由 `scripts/scripture/build.ts`（`npm run data:scripture`）生成、已提交、不手改；运行时由 `src/scripture/catalog.ts` 按需 fetch。不进 Service Worker 预缓存（读到哪卷缓存哪卷）。

## 2. 直属文件

- `index.zh-Hans.json` / `index.zh-Hant.json`：目录，两种文字结构完全相同。`collections`（圣经 / 古兰经 / 佛典 / 儒典 / 道典：名称、版本、传统、出处、许可、分组）、`tracks`（阅读线路：旧约、新约、古兰经、佛典、儒典、道典）、`books`（每部书的名称、简称、署名、段数、字数、每章的题与段数）。
- `SOURCES.json`：逐页的出处与许可——维基文库每页的标题、修订版本号与永久链接，古兰经录入本的来源。署名用。

## 3. 子目录导航

- `books/`：见 `books/.frac.md`；一部书一个语料包，每部书两种文字各一份。

## 4. 本层约束 / 约定 / 禁忌

- 改了分段口径或换了版本，用户浏览器里经卷的足迹与书签会错位（它们按「书 / 章 / 段」的下标记）。

## 5. 什么时候需要下钻

- 加书、换版本、改分段：去 `scripts/scripture/.frac.md`；运行时怎么读见 `src/scripture/.frac.md`。
